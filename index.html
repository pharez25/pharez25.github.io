ResponseStar

ResponseStar is a full-stack survey analytics application developed with MeteorJS, React, and MongoDB. The platform integrates with LimeSurvey and SurveyMonkey, allowing users to effectively categorize and tag free-text responses. Furthermore, it provides detailed analytical insights into survey answers and tagging patterns. As this is a proprietary system, the source code is unavailable.

Ct-Wrap

Ct-Wrap is a serverless wrapper application designed to improve the readability and accessibility of data from clinicaltrials.gov. Built with Node.js and React, it interfaces directly with the ClinicalTrials API to present complex trial information in a highly user-friendly format. The application also supports exporting trial data in various formats for further analysis.

Audiomata

Audiomata is an audio management tool developed for the Unity game engine. It enhances audio flexibility by enabling users to tag audio clips and perform advanced searches based on those tags. Additionally, it leverages command and factory design patterns to provide comprehensive control over audio components, such as allowing gradual fade-in transitions for reverb effects.

m-strat

m-strat is an ongoing project that originated as the final dissertation project for my Master's in Artificial Intelligence. It is an AutoML Directed Acyclic Graph (DAG) framework that enables machine learning developers to construct scriptable blueprints as nodes within a workflow, facilitating highly customisable and data-agnostic processing. By leveraging data-oriented design principles, the framework aims to streamline the creation and rapid prototyping of machine learning models, allowing for quick experimentation and seamless modification of model stack components. The architecture itself is engineered to be highly modular and extensible.
